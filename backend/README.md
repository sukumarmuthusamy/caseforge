# CaseForge backend

The Python package: the deterministic engine, the reasoner, the scenarios, the HTTP API
and the `caseforge` command. It has to be installed from this directory.

```powershell
pip install -e ".[dev]"
pytest
python -m caseforge serve
```

The project overview is in the repository's top-level `README.md`, and the design documents
are in `docs/`.
